Suita 1: Index() Action

    TC 1.1 (Happy Path): Apelarea metodei cere lista tuturor filmelor din baza de date (_unitOfWork.Movie.GetAll()) și o returnează într-un ViewResult.

Suita 2: Upsert() [HttpGet] Action

    TC 2.1 (Add Mode): Dacă id-ul este null sau 0, returnează ViewResult cu o instanță nouă și goală a entității Movie.

    TC 2.2 (Edit Mode - Not Found): Dacă id-ul este valid, dar filmul nu există în baza de date, returnează NotFoundResult.

    TC 2.3 (Edit Mode - Happy Path): Dacă id-ul este găsit, returnează ViewResult transmițând entitatea Movie către interfață.

Suita 3: Upsert() [HttpPost] Action (Async)

    TC 3.1 (Invalid ModelState): Dacă datele trimise din formular nu trec validarea, se returnează direct formularul (ViewResult). Nimic nu este salvat, iar API-ul extern nu este apelat (Times.Never).

    TC 3.2 (Edit Mode - Not Found): Dacă e trimis un formular valid, dar entitatea originală a dispărut din baza de date între timp, returnează NotFoundResult.

    TC 3.3 (Invalid File Type): Dacă utilizatorul atașează un fișier nepermis, sistemul adaugă un mesaj în TempData["error"] și întoarce formularul, fără a atinge baza de date sau API-ul extern.

    TC 3.4 (Add Mode - Sync API Data): Scenariu de creare film nou fără rating-uri IMDB/RottenTomatoes introduse manual. Testul validează că IMovieSyncService este apelat asincron, că datele venite de la serviciul extern sunt mapate corect pe entitate, că se apelează Add(), apoi Save(), și se face redirect.

    TC 3.5 (Edit Mode - Skip Sync): Scenariu de editare unde filmul are deja ImdbRating și RottenTomatoesScore. Testul validează că IMovieSyncService NU este apelat (pentru a economisi limitele de request-uri ale API-ului extern), se apelează Update() și se face redirect.

Suita 4: Delete() [HttpGet] Action

    TC 4.1 (Invalid Request): Dacă id-ul este null, returnează NotFoundResult.

    TC 4.2 (Not Found in DB): Dacă id-ul nu este găsit în baza de date, returnează NotFoundResult.

    TC 4.3 (Happy Path): Dacă este găsit, returnează ViewResult cu detaliile filmului pentru confirmare.

Suita 5: DeletePOST() [HttpPost] Action

    TC 5.1 (Not Found): Dacă filmul care trebuie arhivat nu este găsit, returnează NotFoundResult.

    TC 5.2 (Soft Delete Path): Dacă este găsit, îi modifică starea IsDeleted = true, execută Update(), Save() și redirectează înapoi la Index. Ne asigurăm strict că metoda fizică Remove() nu a fost declanșată accidental.
